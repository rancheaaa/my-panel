# Checklist - 批量文件传输设计文档优化验证清单

- [ ] **1.1 Proxy高可用架构**
  - [ ] 文档包含Proxy集群部署拓扑图（至少2实例 + DB共享）
  - [ ] 明确定义任务调度锁机制实现方案（DB乐观锁或Redis分布式锁）
  - [ ] 描述Leader选举流程和故障转移时间目标（≤30秒）
  - [ ] 提供多实例配置示例（application-cluster.yml）

- [ ] **1.2 数据一致性保障**
  - [ ] 子任务表包含transfer_id唯一约束字段
  - [ ] 定义幂等性检查逻辑（执行前查询状态，已完成的跳过）
  - [ ] 描述Agent重启恢复流程（RocksDB加载 → 状态校验 → 继续传输）
  - [ ] 包含定时一致性校验Job设计（对比Agent报告 vs DB记录）

- [ ] **1.3 子任务生成优化**
  - [ ] 明确分批生成策略（每批1000条，提供进度回调）
  - [ ] 实现懒加载/按需生成选项（配置开关控制）
  - [ ] 增加子任务数量上限校验（默认10万，可配置）
  - [ ] 大任务场景给出用户提示和建议（>5万文件时警告）

- [ ] **1.4 消息可靠性保障**
  - [ ] 设计分发指令ACK/NACK协议（超时重传机制）
  - [ ] 定义失败重试策略（指数退避，最多3次，总超时5分钟）
  - [ ] 包含最终一致性检查Job（定时扫描未确认的分发记录）
  - [ ] 补充分发补偿流程（漏发重传、重复检测）

## 阶段3: 性能优化细化

- [ ] **3.1 进度上报优化**
  - [ ] Agent端聚合缓冲区设计（ConcurrentHashMap + ScheduledExecutorService）
  - [ ] 上报触发条件明确（进度变化>5% 或 静默超过10秒）
  - [ ] Proxy端批量写入实现（Buffer大小100条 或 定时500ms flush）
  - [ ] Redis缓存层配置（key格式、TTL=5s、缓存失效策略）

- [ ] **3.2 数据库性能优化**
  - [ ] 分区表DDL脚本（按月分区，自动创建未来3个月分区）

  - [ ] 高频查询SQL优化建议（EXPLAIN结果分析 + Covering Index）
  - [ ] HikariCP连接池推荐参数（maximumPoolSize, minimumIdle, connectionTimeout等）

- [ ] **3.3 大文件传输优化**
  - [ ] 自适应分块算法伪代码（根据RTT动态调整chunkSize：1MB-16MB）
  - [ ] 多连接并行传输设计（单文件最多4个并发，分块范围分配）
  - [ ] 传输预检步骤（磁盘空间check、带宽预估、预计耗时计算）
  - [ ] 大文件特殊处理规则（>100MB启用优先级队列、断点续传强制开启）
