# Nginx 下载说明

由于安装包较大，不直接存储在源码库中。

### 下载地址
- **Linux**: [http://nginx.org/download/nginx-1.24.0.tar.gz](http://nginx.org/download/nginx-1.24.0.tar.gz)
- **Windows**: [http://nginx.org/download/nginx-1.24.0.zip](http://nginx.org/download/nginx-1.24.0.zip)

### 自动下载
当执行 `mvn package` 时，如果此目录下没有对应的安装包，Maven 会尝试自动下载到此处。
